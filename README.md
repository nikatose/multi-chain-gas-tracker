# ⛽ Multi-Chain Gas Tracker

Real-time gas price tracker for popular EVM networks.

## 🚀 Live Demo

[Open Multi-Chain Gas Tracker](https://nikatose.github.io/multi-chain-gas-tracker/)

## 🌐 Supported Networks

- Ethereum
- Arbitrum One
- Optimism
- Base
- Polygon

## ✨ Features

- Real-time gas prices
- Automatic updates every 15 seconds
- Multiple EVM networks
- No backend
- No API key required
- Responsive design
- Runs entirely in the browser

## 🧠 How It Works

The application communicates directly with blockchain RPC endpoints using the standard `eth_gasPrice` JSON-RPC method.

Gas prices returned in wei are converted to Gwei and displayed in the interface.
